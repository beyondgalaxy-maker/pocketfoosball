# Pocket Foosball

Touchline: a browser-based foosball game for touchscreens, mouse and keyboard.

The game is being added here from the tested Touchline build. It runs as a static website: no accounts, server, API keys, or external game dependencies are required.

## GitHub Pages

Once `index.html` is present, publish the repository root using **Settings → Pages → Deploy from a branch → main → /(root)**. The expected address is `https://beyondgalaxy-maker.github.io/pocketfoosball/`; it is not live until GitHub Pages has been configured and deployment succeeds.

## Controls

Drag the on-table handles to slide and rotate a complete rod. Mint's keyboard pairs are Q/A, W/S, E/D and R/F; Z, X, C and V shoot. Shift or Space makes sliding faster. Mouse and keyboard work together.

Edition 08 introduces an explicit dead-ball recovery countdown and match-persistent bot adaptation. Detailed validation and source files accompany the release.

## Scope

This is a tuned, assisted simulation, not a calibrated replica of a real table or an officially rated opponent.
