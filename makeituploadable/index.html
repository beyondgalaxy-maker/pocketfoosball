A FEW STRAIGHT ANSWERS

Does it upload my files?

No. File processing happens in your browser or the desktop app. The website host receives ordinary page requests, not your selected files. There is no conversion server, advertising tracker or account.

Does it handle absolutely every file?

No tool does. This workspace handles the listed file families, with limits on file variants and available memory. Unsupported files can be saved unchanged or packed into a ZIP. It tells you when a conversion is unavailable.

What is different in the desktop app?

The desktop app adds bundled video/audio conversion and simple-layout Word/text-to-PDF export. The website has image tools, PDF preview and editing, document/spreadsheet previews and ZIP tools. Word conversion can change layout; it is not a substitute for Word’s own export.

What should I know before editing a PDF?

Keep your original. Copying pages can change document-level forms, links and bookmarks. Drawing or stronger compression makes a picture-only PDF, losing selectable text and interactive features. Modifying an existing digital signature invalidates it; the app asks for approval.

Will the website accept the result?

We check the limits you enter and verify supported output files. A destination can have extra rules we cannot see. Review the result, especially before submitting an official document.
